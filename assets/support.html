Experiments

Step-by-step lab guides covering the scientific background, observing procedure, and data analysis for each experiment.

Mapping the Milky Way with the 21 cm hydrogen line

Observe neutral hydrogen across the Milky Way, measure Doppler-shifted 21 cm emission, derive the rotation curve, and reconstruct the positions of the spiral arms.

GNSS satellite signal spectra

Receive and compare radio signals from GPS, Galileo, GLONASS, and BeiDou satellites, and see how their different modulation schemes produce distinct spectral shapes.

Measuring the SALSA antenna beam

Use the Sun as a bright radio source to map the beam pattern of the SALSA antenna, measure its angular resolution, and compare the result to theoretical predictions for a circular aperture.

Planning tools

Target visibility — for a galactic, equatorial, or Sun target on a given date, see when it is above the horizon at the SALSA site (Onsala, Sweden) so you can pick a booking window where it is actually observable. Open the visibility planner.

Data analysis tools

The simplest way to analyse your spectra is in the observation archive, which has built-in baseline subtraction and Gaussian fitting (see the User's manual). To work further with the FITS or CSV files SALSA exports, you can use the tools below. SalsaTS and the Python port are maintained by others, so their features and file-format support may differ from SALSA's own tools.

  • SalsaTS — an analysis tool that runs in the browser, with nothing to install: appolloford.github.io/salsa-ts.
  • SalsaSpectrum (MATLAB) — a MATLAB class for analysing SALSA FITS files, useful for processing many spectra in a script. Download SalsaSpectrum.m and the documentation (PDF). The current version reads files from the present control software; for files from before 2026, use version 2.2 from the historical varenius/salsa repository. The readLab function no longer works, since the Bonn HI survey server closed in September 2026.
  • SalsaSpectrum (Python) — a Python port of the MATLAB class, built on scipy and astropy, with extended baseline modelling, noise estimation and fit-quality diagnostics: github.com/tiagobaroni/SalsaSpectrum.
  • Google Sheets — for a quick look at an exported CSV file without installing anything; see the Google Sheets guide.

Publications

  • A popular science description of SALSA was published by Cathy Horellou and Daniel Johansson in the Swedish magazine Populär astronomi in 2008. PDF (in Swedish).
  • SALSA was mentioned in the article A Radio Astronomical Star Party for those "On The Verge", describing a star party in Onsala, Sweden in 2012. Published in CAPjournal (issue 13, 2013) by Eva Wirström and Robert Cumming. PDF.
  • Thomas Hobiger, Rüdiger Haas and Eskil Varenius describe using the two SALSA telescopes as an educational interferometer demonstrator in Hard and Software Tools for the Education of Geodetic VLBI, published in the IVS 2016 General Meeting Proceedings (NASA/CP-2016-219016, pp. 234–238). PDF.
